C2.2.1 OCR — 실제 문서 수동 전사

이 도구는 인터넷에 연결하지 않습니다. 파일은 현재 브라우저에서만 열리며, 사진이나 전사문을 전송하지 않습니다. 각 검토자는 서로의 전사문과 OCR 출력을 보지 않고 독립 작성해야 합니다.

원본 파일을 수정하거나 압축을 다시 하지 마세요. 검토자는 반드시 동일한 원본 바이트를 사용해야 합니다.
이미지를 선택하면 SHA-256을 계산합니다.

검토 제출 후 절차

서로 다른 두 사람이 동일 이미지에 대해 각자 저장한 reviews/reviewer_a_01.json과 reviews/reviewer_b_01.json 파일을 로컬 비공개 폴더로 모으세요. 원본의 출처·권한·촬영 방법을 별도로 확인한 다음 review-intake.json의 필드를 채우고 python -m ocr_evolution.c221_audit --batch ... --root ... --private-output ...을 실행하세요. 전사 내용이 다르면 자동 통과하지 않고 재검토해야 합니다.

주의: 체크박스는 검토자의 진술입니다. 검토자가 실제 사람인지, 실제 사진인지, 독립적으로 전사했는지는 프로그램이 증명하지 못합니다. CI나 ChatGPT가 체크박스를 대신 선택해서는 안 됩니다.
